# Directory operations — pwd, cd, mkdir

Moving around is `cd`, making folders is `mkdir`, and `pwd` always tells you
where you stand.

## What you will learn

- `pwd` — print the working directory
- `mkdir <dir>` — create a directory
- `cd <dir>` — enter it (`cd ..` goes up, `cd ~` goes home)
- `ls` after every move to confirm where you landed

## Try it

```bash
pwd
mkdir lab
ls
cd lab
pwd
cd ~
pwd
```
