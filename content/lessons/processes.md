# Processes — ps, jobs, kill

See background jobs, understand `kill` semantics — safely simulated, nothing
really dies here.

## What you will learn

- `jobs` — list background jobs
- `ps` — snapshot of running processes
- `kill <pid>` — ask a process to stop (simulated: pid `1234` exists for practice)

## Try it

```bash
jobs
ps
kill 1234
```
