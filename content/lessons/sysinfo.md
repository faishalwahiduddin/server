# System info — uname, df, du, ps, whoami

Four commands answer "what machine is this?": `uname`, `hostname`, `df`, `free` —
plus `ps` and `whoami` for processes and identity. Network commands (`ping`,
`curl`, `ssh`) are disabled by design in the simulator.

## What you will learn

- `uname -a` — kernel and architecture
- `hostname` / `whoami` — machine name / current user
- `df` — disk usage · `du` — directory sizes
- `ps` — process table

## Try it

```bash
uname -a
hostname
whoami
df
ps
```

Every answer is a simulated constant — on a real box the numbers move.
